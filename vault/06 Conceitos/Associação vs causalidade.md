# Associação vs causalidade

Dados observacionais mostram associação. Perguntas do tipo "o que **causa** views?" são recusadas pelo [[Agente - loop do Claude]],
que oferece a análise associativa no lugar. Vale para o [[SHAP]] e para o [[Predictor de títulos]].
Casos "causal" na [[Avaliação - evals]].
