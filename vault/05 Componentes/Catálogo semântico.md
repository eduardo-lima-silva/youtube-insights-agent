# Catálogo semântico (`catalog.py`)

Descrição estável das tabelas do [[Warehouse DuckDB]], com valores válidos (categorias, países) e ressalvas ([[Viés de seleção]]).
Entra no system prompt do [[Agente - loop do Claude]]. É determinístico, o que permite o [[Prompt caching]].
